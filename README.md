# Obligra Verify Examples

Working examples for the Obligra Verify platform.

## Available Examples

| Example | Language | Description |
|---|---|---|
| [Node Basic Capture](./node/basic-capture/) | Node.js | Capture a retained decision record using the Verify SDK |

## Getting Started

Each example includes its own README with setup instructions.

All examples require:

1. A Verify Builder account
2. An API key (created in the Verify Console)
3. The deployed environment URL

## Status

Early Integration Preview — examples are validated against the deployed Verify environment.
